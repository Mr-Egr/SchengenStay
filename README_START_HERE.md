# SchengenStay — Start Here

These documents define a Python-first 90/180 short-stay calculator and travel planning portfolio project.

1. `PRODUCT.md` — user needs, V1 functionality and acceptance criteria.
2. `CALCULATION_RULES.md` — precise arithmetic and unsupported legal cases.
3. `ARCHITECTURE.md` — Python/Pyodide/static hosting and testable architecture.
4. `ROADMAP.md` — staged Codex execution plus a ready-to-paste starter prompt.

**How to begin:** create an empty project/repository; copy all four `.md` specification files into its `docs/` directory (or repository root), then copy the first prompt in ROADMAP.md to Codex. Start with calculation engine and tests, not UI design.

**Source of truth:** official European Commission short-stay calculator/user manual; see CALCULATION_RULES.md. A computational result does not grant immigration rights.
